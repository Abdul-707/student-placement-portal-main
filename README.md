# Student Placement Portal

A TanStack Start placement portal with student, recruiter, tutor, and administrator workspaces. The production target is Vercel for the application and an independent Supabase project for auth/data.

**Migration and deployment:** [Independent Supabase + Vercel setup guide](docs/VERCEL_SUPABASE_MIGRATION.md)

## Local development

Install dependencies with `bun install` and run `bun run dev`.
